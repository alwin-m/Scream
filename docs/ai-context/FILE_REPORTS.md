# File Reports

This is the per-file map future agents should use before opening code. Paths are relative to repository root.

## Root Files

| File | Contains | Read When | Update Notes |
| --- | --- | --- | --- |
| `AGENTS.md` | Instructions for future AI agents to use this doc pack before scanning source. | Any agent workflow/docs task. | Keep routing rules short and strict. |
| `README.md` | Human-facing project intro, current features, build/install notes, older network note. | User-facing overview or setup instructions. | Network section is partly stale because BLE code now exists. |
| `LICENSE` | MIT license. | License/legal task. | Usually do not edit. |
| `.gitignore` | Very small ignore list. | Git/build artifact cleanup tasks. | Currently does not ignore `app/build`, `.gradle`, `gradle-bin`, or APKs. Be careful: many generated files can appear dirty. |
| `generate_icons.py` | PIL script that regenerates launcher icons, web logo, and root logo from an absolute source image. | Icon/logo asset tasks. | Source path points outside repo and may not exist on another machine. |
| `SCREAM-logo.png` | Root logo image generated by `generate_icons.py`. | Brand/icon tasks only. | Binary; avoid opening for normal code tasks. |
| `SCREAM-debug.apk` | Convenience debug APK copy. | Release/install tasks. | Binary build artifact; avoid reading. |

## Networking

| File | Contains | Read When | Update Notes |
| --- | --- | --- | --- |
| `app/src/main/java/com/scream/app/network/P2pMeshEngine.kt` | LAN UDP/TCP engine, shared message envelope, AES-GCM payload encryption, dedupe cache, TTL forwarding, BLE incoming dispatch, dual-protocol BitChat dispatch. Integrates `MessageRouter` and `PeerManager`. | Message routing, protocol, encryption, mesh behavior. | Central protocol owner. Update `NETWORK.md` for any envelope change. |
| `app/src/main/java/com/scream/app/network/BitChatProtocolAdapter.kt` | BitChat protocol adapter implementing `ProtocolAdapter`. Phase 2 will add binary codec. |
| `app/src/main/java/com/scream/app/network/protocol/ProtocolAdapter.kt` | Common interface for all protocol adapters. Defines lifecycle, send/broadcast, listener callbacks. | Adding new protocols, changing adapter contract. | All adapters must implement this interface. |
| `app/src/main/java/com/scream/app/network/protocol/UnifiedMessage.kt` | Protocol-agnostic message, peer address, route, and unified peer models. | Any cross-protocol feature, routing changes, peer display. | Core multi-protocol data types. |
| `app/src/main/java/com/scream/app/network/protocol/ScreamProtocolAdapter.kt` | SCREAM native protocol adapter wrapping JSON envelope and AES-GCM encryption. | SCREAM message format changes, encryption changes. | Mirrors encryption logic from P2pMeshEngine. |
| `app/src/main/java/com/scream/app/network/routing/MessageRouter.kt` | Central message routing engine. Decides which adapter(s) to use for outbound messages. | Routing logic, multi-protocol delivery, adding transports. | Uses PeerManager for route resolution. |
| `app/src/main/java/com/scream/app/network/routing/RoutingPolicy.kt` | Routing decision types and policy configuration. | Changing routing preferences, adding new decision types. | Transport and protocol priority lists. |
| `app/src/main/java/com/scream/app/network/peer/PeerManager.kt` | Unified peer registry across all protocols. Tracks routes, identity linking, stale purge. | Peer tracking, identity mapping, multi-protocol peer queries. | Emits `StateFlow<List<UnifiedPeer>>`. |
| `app/src/main/java/com/scream/app/network/MeshForegroundService.kt` | Persistent foreground service that starts repository, BLE manager, GATT server, and LAN engine. | Background mesh lifecycle. | Returns `START_STICKY`; stops mesh pieces in `onDestroy`. |
| `app/src/main/java/com/scream/app/network/MeshNetworkManager.kt` | BLE advertising/scanning, discovery map, Bluetooth state receiver. | BLE discovery and scan/advertise behavior. | Passes SCREAM devices to `BleGattClient.connectToDevice`. |
